STEP 04

🎬 Multiprocess Pipe → FFmpeg H.264

render_video.py ใช้ ProcessPoolExecutor เรนเดอร์เฟรมขนานทุกคอร์ CPU แล้ว Pipe ไบต์ภาพดิบ rgb24 ตรงเข้า ffmpeg เพื่อเข้ารหัสเป็น libx264 (CRF 18, yuv420p, +faststart) คู่กับเสียง AAC 192k

🇹🇭 กลไกแก้ปัญหาวรรณยุกต์ไทยลอยทับ: _split_thai_lifted()

เมื่อเรนเดอร์ฟอนต์ไทยบน Windows/Pillow โดยไม่มี HarfBuzz (raqm) วรรณยุกต์บนสระอิ/อี/อึ/อือ/ไม้หันอากาศ และหน้าสระอำ (\u0E33) มักซ้อนทับกัน Engine จึงแยกตัววรรณยุกต์ออกมาคำนวณตำแหน่งกึ่งกลางพยัญชนะต้นแล้วยกขึ้น -0.18 × font.size พร้อมวาดเส้นขอบสีดำ (stroke_width) รอบตัวอักษรซับไตเติลสีทอง #FFD54F 

if ch in _TONE_MARKS and (prev_ch in _UPPER_VOWELS or next_ch == "\u0E33"):
    dy = -int(round(font.size * 0.18))
    target_cx = (x_right - font.size * 0.14) if next_ch == "\u0E33" else (x_right - cons_w * 0.36)
    lifted.append((target_cx - glyph_mid, ch, float(dy)))
